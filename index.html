Instructions

  1. Step 1: Open the Starter Code Open the starter code from Getting Started and run it. Click the Check Countdown button. The four boxes still show "(Part ... fills this)" because the JavaScript parts are empty. Now you will fill them, one part at a time. Click the button after each part to test it.
  2. Step 2: Part 1 - Use Null and Undefined In Part 1, make a variable called giftIdea and give it the value null. This means "empty on purpose". Then make a variable called cakeFlavor and do not give it any value. This is undefined. Join both into one text with +, put <br> between them, and show it in the Missing Details box with document.getElementById("missing").innerHTML.
  3. Step 3: Part 2 - Greet by Time of Day In Part 2, get the hour with new Date().getHours(). It is a number from 0 to 23. Use if for "before 12" (morning), else if for "before 17" (afternoon) and else for the evening. Join the greeting and a friendName with +. Show it in the Greeting box with document.getElementById("greeting").innerHTML.
  4. Step 4: Part 3 - Show the Days-Left Message In Part 3, use == to compare daysLeft with 0 and then with 1. If it is 0, the message is "Today is the party!". If it is 1, the message is "Tomorrow is the party!". Otherwise, join daysLeft and the words " days to go until the party!". Show it in the Days Left box with document.getElementById("daysLeft").innerHTML.
  5. Step 5: Part 4 - Count Down with a while Loop In Part 4, make a counter called day that starts at daysLeft. Use a while loop that keeps going while day is 1 or more. Inside the loop, add the text "Days left: " and the counter to your countdown text, with <br> at the end. Use day-- so the counter goes down and the loop stops. After the loop, add "Party time!". Show it in the Countdown box with document.getElementById("countdown").innerHTML.
  6. Step 6: Run and Test Click the button. Check all four boxes. Then change daysLeft to 1 and click again, and then change it to 0 and click again. The Days Left message and the Countdown should change each time.
